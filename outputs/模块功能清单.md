# Qoder Team Workspace — 全模块功能清单

## 一、全局架构概览

IDE 风格三栏布局：左侧边栏（导航 + 文件树）+ 中间内容区（动态视图）+ 右侧面板（上下文信息）。顶部为全局顶栏，承载仓库标识、项目切换器、分支选择器、操作按钮和成员头像堆叠。

技术栈：React 18 + TypeScript + Vite，单文件 CSS（~3500 行），无外部 UI 库。

---

## 二、模块清单

### 模块 1：全局导航与布局（App.tsx + index.css 布局部分）

#### 1.1 顶栏（Topbar）
- 仓库标识区：组织名 / 仓库名（@qoder-team / qoder-team-demo）
- 项目切换器：下拉选择当前项目，显示项目状态（进行中/规划中）和成员数
- 分支选择器：当前分支显示（main），可切换
- 操作按钮：Compare、Pull request
- 成员头像堆叠：显示当前项目核心成员缩略头像

#### 1.2 侧边栏主 Tab（4 个顶级入口）
- **代码**：文件树搜索框 + 可折叠文件树（文件夹/文件层级，支持展开/收起状态记忆）
- **Issues**：占位空状态
- **Pull Requests**：占位空状态
- **团队空间**：NEW 角标，进入团队工作区（5 个子视图）

#### 1.3 团队空间导航（5 个视图）
按分组组织：
- **项目**分组：项目进展（📊）、项目待办（✅，badge=5）
- **协作**分组：Agent 协作（💬，badge=2）
- **管理**分组：知识库（📚，badge=3）、配置与资产（⚙️）

#### 1.4 用户区
- 底部用户卡片：当前用户头像 + 姓名 + 角色

#### 1.5 代码视图占位
- 面包屑导航（src / views / AgentChat.tsx）
- 代码编辑器样式区（行号 + 语法高亮模拟）

### 模块 2：项目进展（ProjectProgress.tsx）

#### 2.1 项目信息头
- 项目名称、描述、状态标签（进行中）、进度百分比
- 时间范围：开始日期、截止日期
- 成员头像列表

#### 2.2 视图切换（3 种模式）
Segment Control 切换：里程碑 / 泳道视图 / 日报

#### 2.3 里程碑视图
- **进度总条**：可视化完成比例（渐变填充动画）
- **里程碑列表**（9 个节点）：
  - 每个节点：状态点（完成-绿/进行中-蓝脉冲/等待-灰）、名称、日期、负责人、状态标签
  - 产物完成度徽章（如 📎 2/4）
  - 点击展开/收起产物详情
  - 阶段门禁（Gate）显示：门禁名称、通过状态（绿色/灰色）
- **产物追踪**（展开后）：
  - 产物列表：图标、名称、知识库关联标记、完成者、完成时间、状态标签
  - 产物类型 6 种：文档📄、代码💻、设计🎨、模型🧠、测试🧪、配置⚙️
- **编辑模式**：
  - 上下移动里程碑顺序
  - 删除里程碑
  - 添加新里程碑（Modal：名称、负责人、日期）
  - 为里程碑添加产物要求（Modal：名称、类型选择）

#### 2.4 泳道视图（6 角色 × L0-L9 矩阵）
- **矩阵表格**：
  - 行：产品📋、设计🎯、前端🎨、后端⚙️、算法🧠、测试🧪
  - 列：L0 需求构想 → L8 发布（共 9 个阶段）
  - 单元格：任务名称 + Agent 参与标记（🤖）+ 状态色（完成绿/进行中蓝/等待白/不适用灰）
  - 阶段门禁（🚪）标记在列头上
- **图例**：已完成/进行中/等待/Agent参与/阶段门禁
- **横向滚动**：最小宽度 800px，角色列 sticky 固定

#### 2.5 日报视图
- **团队日报摘要卡片**：
  - 统计：已完成总数、待完成总数、阻塞项总数（橙色警告）
  - 阻塞项高亮区：列出所有有阻塞的成员及其阻塞内容
- **成员筛选 Tab**：全员 / 各成员独立筛选
- **个人日报卡片网格**（响应式 auto-fill, min 320px）：
  - 头部：头像、姓名、角色、日期
  - 已完成列表（绿色圆点标记）
  - 待完成列表（蓝色圆点标记）
  - 阻塞列表（橙色圆点标记，仅在有阻塞时显示）

#### 2.6 底部信息区（里程碑/泳道视图下显示）
- **最近动态**：Agent/人类活动混合列表，带时间戳和类型标识（绿点=人，蓝点=Agent）
- **产物统计**：总产物要求、已入知识库数、阶段门禁通过情况、阻塞产物数

### 模块 4：Agent 协作（AgentChat.tsx）

#### 4.1 对话列表侧栏（分组组织）
- **👥 全员协作**：全员群聊（1 个固定对话）
- **💬 人员 & Agent**：与每个非自己的成员的单点对话（5 个，带未读 badge、在线状态点）
- **🤖 我的 Agent**：专属 Agent 对话（1 个，带"我的"角标、未读 badge）
- **Agent 任务状态区**：底部固定区域，显示各 Agent 当前任务和状态点（done/running/todo）

#### 4.2 对话内容区
- **对话头部**：返回群聊按钮、对话名称/图标、成员数/角色信息、专属助手标签
- **待确认入口**：如有 pending 事项，显示警告按钮（⚠ N 项待确认）→ 打开审批 Modal
- **对话类型提示条**：根据当前对话类型显示不同提示文案

#### 4.3 消息系统
- 消息类型：人类消息（右侧蓝色气泡）、Agent 消息（左侧白色边框气泡）
- Agent 消息元素：
  - Agent 头像（emoji）
  - 发送者名称 + 所有者标注
  - 目标 Agent 标注（→ 接收方）
  - 时间戳
  - 支持 HTML 内容渲染（dangerouslySetInnerHTML）
  - 代码高亮样式（inline code）
- **产物卡片**：消息内嵌可点击产物，显示类型标签、名称、知识库同步状态

#### 4.4 产物预览 Modal
- 产物类型标签、知识库同步状态
- 代码预览块
- 操作按钮：关闭 / 在知识库查看（或同步至知识库）

#### 4.5 输入区
- 自适应 placeholder：群聊/单聊/我的 Agent 三种文案
- 发送按钮

#### 4.6 待确认审批 Modal
- 所有 pending 事项列表（含已解决和待处理）
- 每个事项：标题、描述、指派方、上下文说明（为什么需要你确认）
- 操作：批准 / 拒绝

#### 4.7 消息数据
- 群聊消息：8 条，含多 Agent 协作链、产物嵌入
- 单点私聊：每成员 2-4 条，模拟真实对话
- 我的 Agent 私聊：5 条，含日报整理、PRD 检查等

### 模块 5：知识库（KnowledgeBase.tsx）

#### 5.1 文档列表
- **来源筛选 Tab**：全部 / Agent 产物 / 个人产物 / 协作产物（带数量统计）
- **Agent 筛选下拉**：按具体 Agent 筛选产物（7 个选项：所有 Agent + 6 个成员 Agent）
- **AI 整理按钮**：打开 Modal 选择自动整理选项（去重、生成摘要、检查过时、关联文档）
- **新建文档按钮**：Modal 输入标题、选择来源类型
- **筛选状态提示**：显示当前 Agent 筛选状态，可一键清除

#### 5.2 文档卡片
- 标题、描述
- 里程碑关联标签（🏁 里程碑名）
- 来源类型标签（Agent产物-蓝/个人产物-紫/协作产物-绿）
- 双文档策略标记（📖↔🤖 配对文档提示）
- 元信息：作者头像+姓名+角色、Agent 名、更新时间、版本号、阅读提示

#### 5.3 文档阅读/编辑模态框（全屏浮层）
- **头部**：
  - 标题（编辑时为 input）
  - 来源标签 + 里程碑标签 + 版本/时间
  - 操作按钮：编辑/保存/取消/关闭
- **作者信息栏**：头像、作者、Agent、贡献者数
- **内容区**：
  - 阅读模式：描述 + 正文（pre 格式化文本，等宽字体）
  - 编辑模式：描述 textarea + 内容 textarea（大文本框，等宽字体）
- **Agent 协作栏**（仅编辑模式）：
  - "召唤我的 Agent 参与修改" 按钮
  - Agent 思考中动画（脉冲点 + 文字）
  - Agent 建议卡片：建议内容 + 采纳并插入 / 忽略 按钮
  - 采纳后追加到文档内容末尾

#### 5.4 版本管理
- 保存时自动 bump 版本号（v1.2 → v1.3）
- 更新时间为"刚刚"

## 三、当前问题与重构机会

1. **CSS 集中化**：全部样式在一个 3500 行的 CSS 文件中，按模块拆分可提升可维护性
2. **数据散落**：各视图有局部数据定义，虽已统一部分到 data.ts，但视图内仍有不少局部数据
3. **类型重复**：shared.tsx 中遗留的旧接口与新代码中的接口并存
4. **组件粒度**：视图文件过大（ConfigView 26KB、ProjectProgress 35KB），可拆分为子组件
5. **Modal 管理**：使用 DOM getElementById 读取表单值，可优化为受控组件
6. **未使用代码**：AgentQA 视图未在路由中注册
7. **CSS 重复**：modal-overlay 在两个地方定义（shared Modal 和 KB 阅读模态）
